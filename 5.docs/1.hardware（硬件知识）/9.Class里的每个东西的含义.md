Class 与 Object

Class：对象的设计模板，规定对象有哪些属性和方法。

Object：根据 Class 创建出来的具体实例。

一个 Class 可以创建多个 Object。



---

self 的含义

> 谁调用方法，self 就是谁。



例如：

left_motor.forward() → self 代表 left_motor

right_motor.forward() → self 代表 right_motor


因此，不同对象拥有各自独立的属性。


---

属性（State）与参数（Parameter）

参数（如 speed）：

函数调用时临时传入的数据。


属性（如 self.speed）：

对象长期保存的数据，函数结束后仍然存在。



---

Motor 类职责

Motor 负责：

管理自己的运行状态。

保存当前速度、方向和运行状态。

接收 Controller 的命令。

控制 GPIO 与 PWM 输出。


Controller 不负责：

控制具体 GPIO。

管理 Motor 内部状态。



---

PWM 的职责

PWM 对象负责保存：

控制引脚

工作频率

当前占空比


PWM 负责控制平均输出功率，不负责决定电机旋转方向。


---

H 桥控制思想

方向由 AIN1、AIN2 控制。

速度由 PWM 控制。

两者职责相互独立。


---

软件状态与硬件状态

停止电机时：

软件可以决定：

是否保留 speed

是否清零 speed


硬件可以决定：

修改方向控制引脚

是否修改 PWM 输出


具体设计应根据系统需求决定，没有唯一标准答案。
