开环：Controller 只有输出指令，没有实际状态反馈。

闭环：Controller 获取实际状态，与目标值比较后调整输出。

电机 PWM/控制输出不等于实际速度，实际速度会受到摩擦、负载、电压、电机差异等因素影响。

编码器可用于获取电机实际运动状态，为速度闭环提供反馈。

新增：开环与闭环控制基础

开环：
目标 → Controller → Motor → 实际运动
                         ↓
                    没有反馈

闭环：
目标 → Controller → Motor → 实际运动
         ↑                  ↓
         └──── 反馈 ← Encoder

补充认识：

Motor 的控制输入不等于实际运动状态。

实际速度会受到负载、摩擦、电压、电机差异等因素影响。

要让 Controller 根据真实速度进行调整，需要反馈信息。

编码器可以作为后续速度闭环的反馈来源。
