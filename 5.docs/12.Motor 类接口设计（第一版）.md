新增：PWM 速度映射

软件层速度：

0 ~ 100

映射到硬件 PWM：

0 ~ 65535

计算公式：

PWM = speed / 100 × 65535

新增：软件设计原则

参数（speed）表示外部传入的数据。

属性（self.speed）表示对象保存的当前状态。

类内部调用自己的方法，应使用 self.方法名()。

动作接口（forward()、backward()）可以调用基础接口（set_speed()），避免重复代码。

修正输入数据后，再统一判断是否需要更新状态，最后再更新硬件输出。
