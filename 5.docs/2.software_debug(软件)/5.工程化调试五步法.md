用途： RobotLab 后续遇到 Bug 时的统一调试方法。

核心流程：

> 现象 → 假设 → 最小实验 → 排除/缩小范围 → 修改 → 完整验证



具体原则：

先准确描述现象，不急着下结论。

可以凭经验提出假设，但假设必须通过实验验证。

每次实验尽量只改变一个变量。

根据实验结果排除错误假设，而不是不断凭感觉换方案。

修复后必须重新验证原来的完整功能链。

区分“定位问题”和“修复问题”。

记录真实实验结果，而不是只记录最终答案。


能力成长方式：

当前阶段：

> 助手设计实验 → 用户执行 → 用户反馈 → 助手解释



后续逐渐过渡到：

> 用户提出假设 → 用户设计实验 → 助手检查方案



最终目标：

> 用户能够独立定位机器人系统中的软件、硬件、接口和控制问题。
