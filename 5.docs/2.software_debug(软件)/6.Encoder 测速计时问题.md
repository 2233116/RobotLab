# Encoder 测速计时问题

## 问题

Encoder 原先使用 time.time() 计算测速时间：

self.current_time = time.time()

当前 ESP32 环境下 time.time() 为整数秒级，因此无法形成真正的 0.2 s 测速窗口。

## 验证

测试得到：

time.time()：整数秒
ticks_ms()：毫秒级

并验证：

ticks_diff(current_time, start_time) = 200 ms

因此 ticks_ms() 可以满足 0.2 s 测速窗口要求。

## 修正

Encoder 改用：

ticks_ms()
ticks_diff()

并将毫秒转换为秒：

elapsed_time = ticks_diff(current_time, start_time) / 1000

从而使：

elapsed_time >= 0.2

真正代表约 0.2 秒的测速窗口。

## 验证结果

修正后测速数据中：

time ≈ 0.201~0.202 s

pulse_count 与 RPM 计算结果能够对应。

因此确认：
- 计时方式原先存在问题；
- 修正后 0.2 s 测速窗口正常；
- 当前没有证据表明 RPM 计算公式本身错误。
