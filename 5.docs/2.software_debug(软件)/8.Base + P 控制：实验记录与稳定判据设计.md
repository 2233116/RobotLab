Base + P 控制：实验记录与稳定判据设计

1. 文档目的

记录 RobotLab 中第一次实际运行：

«Base PWM + P 修正»

的实验过程、数据、问题以及后续控制逻辑设计。

---

2. 控制结构

本阶段采用：

PWM = Base PWM + Kp × Error

其中：

Error = Target Speed - Current Speed

即：

error = target_speed - encoder.current_speed
pwm = base_pwm + kp * error

PWM 最终限制在：

0 ≤ PWM ≤ 100

---

3. Base PWM 的作用

Base PWM 的目的不是完成精确控制，而是：

«给电机一个接近目标运行状态所需要的基本动力。»

例如：

目标速度 = 50 RPM
Base PWM ≈ 20

如果实际速度刚好接近 50 RPM，则 P 修正量应该很小。

因此理想状态是：

Base PWM
    +
较小的反馈修正
    ↓
目标速度

---

4. Base PWM 的来源

不能默认：

base_pwm = target_speed / 2

这种关系对不同电机、负载、电池电压和工作状态都成立。

当前已有实测数据：

PWM| 实际速度
40| 约 85~88 RPM
50| 约 103~106 RPM

因此：

«目标 50 RPM 对应的 Base PWM 应该通过实际实验估计，而不是直接使用 "target_speed / 2"。»

后续可以通过更多固定 PWM 数据建立更可靠的 PWM→RPM 对应关系。

7. 原因分析

7.1 电机存在动态响应

改变 PWM 后：

PWM 改变
↓
电机产生响应
↓
转速逐渐变化
↓
Encoder 测量

不是：

PWM 改变
↓
RPM 立即改变到最终值

因此控制器不能假设 PWM 修改后速度立即稳定。

---

7.2 Encoder 的测速不是瞬时值

当前 Encoder 的：

update()

大约每 0.2 秒产生一次新的速度值。

"current_speed" 表示一个测速时间窗口内得到的平均速度。

因此：

current_speed

不是电机某一瞬间的精确转速。

这意味着控制器每次修改 PWM 后，需要考虑电机响应时间和测速窗口。

---

8. 稳定状态的定义

当前形成的设计思想：

«稳定 ≠ 达标。»

需要同时考虑：

条件 A：速度是否在目标范围内

例如：

目标 = 50 RPM

允许范围可以是：

目标 ± 允许误差

例如：

48~52 RPM

具体范围以后根据实验确定。

---

条件 B：速度是否已经稳定

例如：

49.5
50.0
50.2
49.9

变化较小，可以认为已经基本稳定。

而：

42
46
50
54

虽然都获得了测速值，但速度仍明显在变化，不能认为稳定。

---

9. 稳定判据的第一版设计

稳定判断暂时考虑两个维度：

速度变化幅度
+
连续满足次数

形式上：

|current_speed - previous_speed| < threshold

并且：

连续满足 N 次

当前候选：

N = 3

因为当前 Encoder 约每 0.2 秒更新一次：

3 次 ≈ 0.6 秒

但 "threshold" 不直接拍脑袋决定。

---

10. 稳定阈值的确定方法

下一步先进行固定 PWM 实验。

例如：

固定 PWM
↓
电机运行
↓
等待进入稳定阶段
↓
连续记录 current_speed

观察稳定阶段：

速度平均值
最高值
最低值
相邻测速变化

再根据实际波动确定：

threshold

这样得到的稳定阈值具有实际电机依据。

13. 当前控制思想

目前形成的控制逻辑可以概括为：

                ┌─────────────┐
                │  测量速度    │
                └──────┬──────┘
                       ↓
                  计算速度误差
                       ↓
               是否在目标范围？
                  /          \
                是            否
                ↓              ↓
          是否稳定？       判断偏差状态
           /     \              ↓
         是       否          调整 PWM
         ↓        ↓
      保持PWM   继续观察
         ↓
      持续监测
         ↓
    出现新的偏差？
         ↓
      重新调整

注意：

«“保持 PWM”只是暂时不修改 PWM，不代表停止闭环监测。»

14. 与增量式 P 的区别

必须区分两种写法。

Base + P

pwm = base_pwm + kp * error

特点：

«每次根据 Base 和当前误差重新计算 PWM。»

例如：

Base = 20
Error = 10
→ PWM = 21

Error = 5
→ PWM = 20.5

---

增量式 P

PWM_new = PWM_old + Kp × error

特点：

«当前 PWM 会在上一次 PWM 的基础上继续进行修正。»

例如：

PWM = 20
Error = +10
→ PWM = 21

下一次 Error = +5
→ PWM = 21.5

两者控制行为不同。

不能混为一谈。

17. 核心原则

原则 1

«先测系统，再定控制参数。»

原则 2

«稳定不等于达标。»

原则 3

«保持 PWM 不等于停止闭环监测。»

原则 4

«电机控制必须考虑系统动态响应，不能把 PWM 修改看成 RPM 立即变化。»

原则 5

«Base 提供大致动力，反馈负责修正误差。»
