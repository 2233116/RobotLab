# 双电机独立 PID：配置与验证记录

## 1. 目的

记录 ESP32-WROOM-32 上双电机独立速度闭环的实现、已验证的硬件映射和初步测试结果，作为后续底盘控制整合的基线。

## 2. 硬件映射

| 项目 | 左侧 | 右侧 |
|---|---|---|
| Motor 对象 | `Motor(33, 27)` | `Motor(13, 12)` |
| Encoder 对象 | `Encoder(4, 5, 22, 56)` | `Encoder(21, 22, 22, 56)` |
| PID 对象 | `left_pid` | `right_pid` |
| 正向反馈 | 前进时为正 | 前进时为正 |

电机与编码器的引脚映射均经过实际方向测试。修改前必须先对照本记录，不能仅根据左右对称关系推测接线顺序。

## 3. PID 参数与更新方式

- 目标转速：100 RPM
- Kp：0.25
- Ki：0.3
- Kd：0.05
- 编码器采样窗口：达到约 0.2 秒后更新一次速度
- PID 更新：每侧累计三次有效编码器采样后更新一次
- `dt`：该侧三次采样对应的 `elapsed_time` 累计值

左右两侧分别维护采样计数、累计时间和 PID 实例。不能假设左右编码器一定在同一轮循环中同时更新。

当前实现使用每侧最近一次计算出的 `current_speed` 进行 PID 更新，而不是三次速度的平均值。这是当前基线的行为，暂不改变。
