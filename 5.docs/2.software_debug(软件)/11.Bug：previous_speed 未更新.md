previous_speed = None 

虽然完成了初始化，但没有在新的 Encoder 测量结果产生后执行：

previous_speed = encoder.current_speed 

因此：

if previous_speed is not None: 

无法正常进入。

解决

在每次：

encoder.update() 

成功得到新测速结果后更新：

previous_speed = encoder.current_speed
