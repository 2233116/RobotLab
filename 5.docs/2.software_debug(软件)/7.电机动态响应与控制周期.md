1. 电机不是 PWM 改变后立即达到对应速度

电机从一个 PWM 改变到另一个 PWM 后，需要经过一定时间才能达到新的稳定转速。

因此：

«当前时刻测得的 RPM 可能只是动态响应过程中的速度，而不是当前 PWM 对应的最终稳态速度。»

例如：

PWM=50 时，实际测得速度可能经历：

0 → 44 → 86 → 97 → 101 → 104+ RPM。

2. PWM 降低后 RPM 不一定立即降低

电机转子具有惯性。

当 PWM 降低时：

PWM降低 → 驱动力减小 → 电机仍保持原有运动状态 → 如果此时驱动力仍大于阻力，RPM仍可能继续上升 → 驱动力不足后才开始减速。

因此“PWM下降但RPM继续上升”属于正常的动态响应现象。

3. 测速窗口与控制周期需要区分

Encoder 的测速窗口约为 0.2 s。

这表示 Encoder 每经过一定时间可以计算一次新的平均速度。

但：

«Encoder 的测速周期不等于控制器必须采用的控制更新周期。»

控制器需要根据被控对象的动态响应速度决定多久调整一次输入。

4. P 控制与动态响应

增量式 P：

PWM_new = PWM_old + Kp × error

其中 Kp 决定一次调整的幅度。

Kp过大：

- PWM变化幅度大
- 响应可能更快
- 更容易过冲和震荡

Kp过小：

- PWM变化幅度小
- 控制更加温和
- 但响应可能过慢

P 控制是否稳定不能简单归结为“P一定会震荡”，而需要考虑 Kp、控制周期和被控对象动态响应之间的匹配。

5. PWM-RPM 对应关系的作用

通过开环实验可以得到近似的 PWM-RPM 对应关系。

当前实验得到：

PWM 40 → 约87 RPM

PWM 50 → 约104~106 RPM

因此目标100 RPM时，可以估计基础 PWM 约为47~48。
