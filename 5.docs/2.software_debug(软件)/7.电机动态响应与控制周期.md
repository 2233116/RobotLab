电机动态响应与控制周期

1. 电机不会在 PWM 改变后立即达到对应速度

电机从一个 PWM 改变到另一个 PWM 后，需要经过一定时间才能达到新的稳定转速。

例如，PWM 从较低值提高后，实际转速可能经历：

"0 → 44 → 86 → 97 → 101 → 104 RPM"

以上只是用于说明动态响应过程的示意，不代表固定的电机测试数据。

因此：

当前时刻测得的 RPM 可能只是动态响应过程中的速度，而不是当前 PWM 对应的最终稳态速度。

在分析电机控制效果时，需要区分启动阶段、目标改变后的瞬态过程和稳定运行阶段。

2. PWM 降低后，RPM 不一定立即降低

电机转子具有惯性。

当 PWM 降低时，电机的驱动力会减小，但转子不会立即停止原有运动。如果此时电机仍在加速，转速可能短时间继续上升；随后随着驱动力、负载和阻力的变化，转速才逐渐下降并趋于新的平衡状态。

因此，观察到：

"PWM 下降，但 RPM 暂时继续上升"

并不一定代表程序错误。需要结合目标变化时间、测速窗口和控制更新时机判断。

不能只根据相邻的两条日志就认定控制方向错误。

3. 测速窗口与控制周期需要区分

当前 Encoder 的测速窗口约为 0.2 秒。

这表示 Encoder 在经过一定时间后，可以根据累计的编码器脉冲和实际经过的时间计算一次新的速度。

但：

Encoder 的测速周期不等于控制器必须采用的控制更新周期。

当前控制器每侧累计三次有效测速更新后，才执行一次 PID 更新，并把对应的 "elapsed_time" 累加作为本次 PID 的 "dt"。

因此，当前设计的控制周期约为 0.6 秒，但实际时间应以累计的 "elapsed_time" 为准，不能把约 0.6 秒视为严格固定的时间。

控制更新周期应结合被控对象的动态响应、测速噪声、执行环境和控制算法进行选择，而不是单纯追求更快更新。

4. P 控制与动态响应

在增量式 P 控制中，可以用下面的形式表示控制量变化：

"PWM_new = PWM_old + Kp × error"

其中：

- "PWM_old"：上一次的控制输出；
- "PWM_new"：本次更新后的控制输出；
- "error"：按当前定义计算的速度误差；
- "Kp"：比例调节系数。

实际项目中还需要考虑 PWM 上下限以及输出限制。

Kp 过大

- 控制输出调整幅度较大；
- 可能加快响应；
- 也可能增加超调、振荡或输出饱和风险。

Kp 过小

- 控制输出调整更加温和；
- 可能减少过大的控制动作；
- 但响应可能变慢，误差消除也可能较慢。

P 控制是否稳定，不能简单归结为“P 一定会震荡”。需要综合考虑 Kp、控制周期、测速特性和电机本身的动态响应。

**注意：**以上是 P 控制的基本分析原则。当前项目已经有双电机独立 PID 闭环基线，后续不应在没有测试依据的情况下随意切换控制算法。

5. PWM-RPM 对应关系的作用

此前开环实验中记录了以下近似关系：

PWM| 实测速度
40| 约 87 RPM
50| 约 104–106 RPM

这些数据表明，在当时的实验条件下，PWM 与转速之间存在可用于估算的近似关系。

根据这组记录，目标为 100 RPM 时，可以初步估计基础 PWM 在 47–48 附近。

但这只是估算值，不应直接当成所有负载、电池电压和运行状态下的固定映射。电机差异、负载变化、供电电压和驱动损耗都会影响结果。

此前提出过“基础 PWM + P 反馈修正”的思路：先利用基础 PWM 将电机带到目标附近，再由反馈控制修正误差。

这属于备选控制方案。当前阶段优先验证现有双电机闭环控制的动态响应，不因已有近似映射就提前更换控制架构。

6. 当前双电机闭环控制基线

当前控制系统具有以下特征：

- 左右电机独立闭环控制；
- 每侧使用独立的 Encoder、PID 和 MotorController 实例；
- Encoder 测速窗口约为 0.2 秒；
- 每侧累计三次有效测速更新后执行一次 PID；
- PID 使用累计的实际 "dt"；
- 当前 PID 参数为 "Kp = 0.25"、"Ki = 0.3"、"Kd = 0.05"。

此前目标速度为 100 RPM 的双电机测试中，左右电机均可运行在目标附近。这组配置作为当前实验基线，未经对照验证不应随意更换。

7. MotorController 封装后的进度

2026-10-22，已将单侧电机的测速计数、时间累计、PID 更新和 PWM 输出封装到 "MotorController"。

主程序负责创建左右两侧对象，并在主循环中分别调用：

while True:
    left_motorcontroller.update()
    right_motorcontroller.update()

封装后，左右两侧分别管理自己的采样计数和累计时间，不假设两侧编码器总会同时更新。

目标速度设为 90 RPM 的初步测试中，启动初期出现过较大波动，随后速度读数多数收敛到约 88–94 RPM。

该现象提示启动阶段与稳态阶段需要分别分析，但尚不足以得出完整的动态性能结论。

8. 下一阶段：目标速度阶跃测试

本阶段先保持硬件连接、PID 参数和控制结构不变，只改变目标速度。

测试 A：90 RPM 稳态基线

1. 将左右电机目标速度设为 90 RPM。
2. 等待启动阶段过去。
3. 记录左右速度和 PWM 的稳定情况。
4. 保存稳定前后的数据，作为后续比较基线。

测试 B：90 RPM 降至 60 RPM

1. 系统在 90 RPM 附近稳定后，将目标改为 60 RPM。
2. 观察左右速度如何变化。
3. 记录是否出现短暂继续上升、超调或明显波动。
4. 记录进入稳定范围所需的时间。

测试 C：60 RPM 升至 120 RPM

1. 系统在 60 RPM 附近稳定后，将目标改为 120 RPM。
2. 观察速度上升过程。
3. 记录超调、稳定时间和 PWM 的变化。
4. 对比左右两侧的响应差异。

建议记录字段

字段| 记录内容
目标速度| 当前设定 RPM
左侧实际速度| 当前测速值
右侧实际速度| 当前测速值
左侧 PWM| 当前控制输出
右侧 PWM| 当前控制输出
目标改变时间| 每次阶跃的时间点
响应过程| 上升、下降、超调或异常波动
稳定时间| 达到并保持预定稳定范围的时间

测试前应明确“稳定范围”的判断标准，避免只凭主观感觉判断稳定。

左右两侧的测速和控制更新不一定同步，因此应分别观察，不能只用单侧数据代表整个系统。

9. 数据分析原则

- 将启动瞬态与稳态波动分开记录。
- 不根据单次测速值就认定系统稳定或失稳。
- 先检查实际目标变化、速度反馈和 PWM 输出是否符合预期，再判断是否需要调整参数。
- 每次尽量只改变一个变量。
- 只有在获得可比较的实验数据后，才决定是否调整 PID 参数或控制周期。

10. 测试安全

电机测试时让车轮离地，避免车辆突然运动。

单次测试应保持短时运行。若出现 PWM 长时间饱和、驱动板异常发热、异味或异常声响，应立即停止并断电检查。

在动态响应验证完成前，不应通过长时间高 PWM 输出强行完成测试。
