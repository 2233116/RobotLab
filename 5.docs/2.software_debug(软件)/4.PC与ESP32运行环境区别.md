主题：PC Python 与 ESP32 MicroPython 的运行环境区别

RobotLab 中的部分模块是面向 ESP32 MicroPython 编写的，因此不能假设所有模块都可以直接在 PC Python 环境中运行。

Motor 模块依赖 MicroPython 的硬件相关功能，其中包括 machine 模块。PC 上运行测试时，如果导入这类模块，就可能出现模块不存在的问题。

因此需要区分：

PC 端：

用于测试不依赖具体硬件的逻辑，例如：

Controller 的数据处理

DifferentialDrive 的轮速计算

参数和结果的逻辑验证


ESP32 端：

用于测试依赖实际硬件的功能，例如：

GPIO

PWM

Motor

TB6612

实际电机运动


调试原则：

不要为了让硬件模块通过 PC Python 测试而随意安装、伪造或修改硬件依赖模块。

应该根据代码实际运行环境选择测试平台。

因此 RobotLab 后续可以逐渐形成：

PC 逻辑测试 → ESP32 实机测试

两层验证方式。

进一步明确：

PC Python 环境和 ESP32 MicroPython 环境不是同一个运行环境。

machine 属于 MicroPython 硬件相关模块。

逻辑测试可以在 PC 上完成。

GPIO、PWM、Motor 和实际电机行为需要在 ESP32 实机环境验证。

PC 测试无法完全替代硬件实机测试。
