PID 积分抗饱和与当前控制基线

1. 背景

在单电机速度闭环中，当目标转速超过电机在当前供电和负载下能够达到的转速时，PWM 可能持续达到输出上限。

如果积分项仍不断累积，即使执行器已经无法继续增加输出，积分仍会增长。目标恢复正常后，过大的积分可能使系统难以快速恢复。

2. 当前 PID 基线

参数| 当前值
Kp| 0.25
Ki| 0.3
Kd| 0.05
目标转速| 100 RPM
控制更新周期| 约 0.6 s
PWM 限幅| -100 至 100

当前实现使用速度误差：

"error = target_speed - current_speed"

积分按实际控制时间累积：

"integral_error += error * dt"

微分项使用测量转速的变化率：

"D = kd * (previous_speed - current_speed) / dt"

第一次更新时没有上一时刻转速，故 "D = 0"。

3. 抗饱和逻辑

当前实现根据上一次实际限幅后的 PWM 和当前误差方向处理积分。

上一次 PWM| 当前误差| 积分处理
+100| 正误差| 冻结积分
+100| 负误差| 清除积分
-100| 负误差| 冻结积分
-100| 正误差| 清除积分
其他情况| 任意| 正常积分，并限制积分范围

积分变量范围为 -1000 至 1000。

注意：使用的是上一次更新保存的实际 PWM，因为本次输出尚未计算完成。该逻辑属于当前项目采用的简化抗饱和策略，不应未经对照测试就替换成其他实现。

4. 实机验证

测试 A：目标转速提高至 200 RPM。

- 电机实际最高转速约 164–165 RPM。
- PWM 达到 100。
- 正误差持续存在时，积分没有持续增长。

测试 B：随后将目标恢复至 100 RPM。

- 当前误差转为负值。
- 由于上一次 PWM 为 100，积分被清除。
- 控制输出重新调整，转速重新回到目标附近。

验收时没有观察到突然停转、卡轮、异常发热或异味。结论仅适用于已测试的硬件和工况。

5. 控制周期结论

比较约 0.6 s 与 0.8 s 的更新周期后，保留约 0.6 s 作为当前基线。

当前没有足够证据要求继续调整 D 项或引入滤波，因此不在本阶段扩展优化。

6. 当前限制

- 单电机实机验收不等于双电机系统已验收。
- 电机、驱动板、供电、负载和底盘结构都会影响实际控制效果。
- PWM 达到限幅时的积分处理已经过当前测试，但尚未覆盖全部负载与工况。
- 双电机阶段需要分别确认左右电机的方向、编码器符号和速度测量，再建立独立控制回路。

7. 后续执行顺序

1. 左电机独立基线验证。
2. 右电机独立基线验证。
3. 两台电机同时运行与测速。
4. 左右独立速度闭环。
5. 差速运动与底盘结构验证。

遵循“基线 → 对照 → 验证 → 修改”，未经实机验证，不替换当前基线。
