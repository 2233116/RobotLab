
1. PWM 两个核心参数

频率（Frequency）

表示：

> 一秒钟重复多少个 PWM 周期。



关系：

周期（T） = 1 / 频率（f）

频率越高，一个 PWM 周期越短。


---

占空比（Duty Cycle）

表示：

> 一个 PWM 周期内，通电时间所占的比例。



例如：

30%

50%

80%


工程中通常通过修改占空比来调节电机速度。


---

2. 为什么工程中通常固定频率

低频（例如 1Hz）：

电机有足够时间停下来。

会出现明显的转—停—转现象。


正常 PWM 工作频率（几百 Hz～几千 Hz）：

电机由于惯性无法停下来。

调速主要依赖占空比。

频率更多影响控制品质（噪声、效率等），而不是作为主要调速手段。



---

3. Pin 与 PWM 的职责

AIN1：

高电平 / 低电平

控制方向

使用 Pin 对象


AIN2：

高电平 / 低电平

控制方向

使用 Pin 对象


PWMA：

控制占空比

调节电机平均供电

使用 PWM 对象


设计原则：

> 根据职责选择对象类型，而不是为了统一写法。




---

4. 属性（Attribute）与参数（Parameter）

属性：

属于对象长期保存的状态。

例如：

self.speed
self.direction
self.is_running

参数：

函数调用时临时传入的数据。

例如：

forward(speed)

调用结束后：

参数消失。

属性继续保存在对象内部。



---

5. Controller 与 Motor 的数据流

Controller
      │
motor.forward(50)
      │
      ▼
参数 speed = 50
      │
      ▼
Motor
      │
self.speed = speed
      │
      ▼
Motor 保存当前状态
