主题：
软件防抖（Software Debounce）

问题：

机械按钮按下时会产生抖动。

例如：

1
0
1
0
0
1
0

程序可能误认为多次按下。


解决方案：

记录上一次有效按下时间：

last_pressed_time

当满足：

current_time - last_pressed_time > 50

才允许触发。


效果：

50ms内所有重复触发全部忽略。

只保留第一次有效按下。

主题：
PWM

PWM：
Pulse Width Modulation

脉冲宽度调制。

作用：

通过快速开关输出模拟不同平均功率。

应用：

LED亮度调节

电机速度调节

占空比越高：

输出功率越大。

电机转速越快。
