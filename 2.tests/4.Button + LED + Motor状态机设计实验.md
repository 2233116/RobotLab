实验名称：

Button + LED + Motor状态机设计实验


实验目标：

设计一个简单机器人控制框架。


实验设备：

Button ×3

LED ×1

Motor ×1


实验逻辑：

ButtonA：

总开关

enable切换


ButtonB：

LED模式切换

0 → off
1 → on
2 → blink


ButtonC：

Motor模式切换

0 → stop
1 → forward
2 → backward


实验结果：

完成状态机设计。

完成Controller框架设计。

完成LED模式切换逻辑设计。

完成Motor模式切换逻辑设计。

完成enable总开关设计。
