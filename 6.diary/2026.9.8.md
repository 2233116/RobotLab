2026-09-08｜目标速度、误差与简易 P 控制

在昨天完成 Motor + Encoder 实时测速的基础上，开始学习闭环控制的基本概念。

建立：

target_speed → actual_speed → error → 调整 PWM

理解误差：

error = target_speed - actual_speed

error > 0：实际速度低于目标速度，应提高 PWM。

error < 0：实际速度高于目标速度，应降低 PWM。


理解比例控制的核心思想：

adjust = Kp * error

误差越大，调整量越大；误差越小，调整量越小。

理解 PWM 的调整必须建立在当前 PWM的基础上持续修正，而不是每次循环重新从初始值开始。

实际查看 motor.py，理解 set_speed() 中：

int(speed / 100 * 65535)

将程序中的控制值映射为 ESP32 的 PWM 数值。

明确当前 Motor 接口的控制范围为 -100 ~ 100，其中 100 对应 duty_u16(65535)，即当前接口下的最大 PWM 输出。

理解程序中的 speed 与最终 PWM 硬件值属于不同层级；即使不同的 speed 最终映射到相同的整数 PWM 值，Motor 仍可能继续执行。

理解 PWM 限幅的意义：避免控制器内部的 PWM 状态无限增长，并使控制器状态与实际可输出范围保持一致。

理解控制周期的重要性：如果控制器疯狂循环，Encoder 可能还没有产生新的有效测速结果，而控制器已经连续修改很多次 PWM，导致控制动作远快于电机实际响应。
