2. 今日使用的控制公式

error = target_speed - encoder.current_speed
pwm = base_pwm + kp * error

并对 PWM 做 0~100 限幅。

本次实验参数：

target_speed = 50 RPM
base_pwm = target_speed / 2 = 25
kp = 0.1

---

3. 本次测试代码

from motor import Motor
from encoder import Encoder
from time import sleep

motor = Motor(33,27)
encoder = Encoder(4,5,22,56)

kp = 0.1
target_speed = 50
base_pwm = target_speed / 2

motor.set_speed(base_pwm)

while True:
    if encoder.update():
        error = target_speed - encoder.current_speed

        pwm = base_pwm + kp * error

        if pwm > 100:
            pwm = 100
        elif pwm < 0:
            pwm = 0

        motor.set_speed(pwm)

        print("pwm: \n", pwm)
        print("error: \n", error)
        print("current_speed: \n", encoder.current_speed)

    sleep(0.2)

5. 对实验现象的理解

5.1 Base + P 公式本身工作正常

例如：

目标 = 50 RPM
实际 = 40 RPM
error = +10

则：

PWM = 25 + 0.1 × 10
    = 26

实际速度低于目标，所以 PWM 增加。

如果：

实际 = 55 RPM
error = -5

则：

PWM = 25 + 0.1 × (-5)
    = 24.5

实际速度高于目标，所以 PWM 减小。

因此：

«正误差 → 增加 PWM
负误差 → 减小 PWM»

---

5.2 Base PWM = target / 2 只是暂时估计

本次：

target_speed = 50
base_pwm = 25

并不是通过实际电机实验得到的精确关系。

之前的固定 PWM 实验已经得到：

PWM 40 → 约 85~88 RPM
PWM 50 → 约 103~106 RPM

因此 50 RPM 所需的基础 PWM 实际上应该明显低于 25。

本次实验中：

PWM ≈ 24.x

却出现：

≈ 58 RPM

也进一步说明：

«Base PWM 应该尽量来自实际的 PWM→RPM 实验，而不是简单通过目标速度除以一个常数得到。»

6. 今天最重要的控制思想

今天从实验中进一步认识到：

«稳定不等于达标。»

例如目标为 50 RPM：

可以认为已经在目标附近稳定。

但：

虽然也很稳定，但它稳定在错误的速度。

因此控制器不能简单使用：

«“速度稳定了 → 不再控制”»

而应该：

«“速度稳定且处于目标范围 → 当前 PWM 可以保持，但仍然继续监测。”»

如果之后出现负载变化：

控制器需要发现速度偏离，并重新调整 PWM。

如果：

虽然速度已经稳定，但因为稳定在目标范围之外，也需要重新调整。

7. 关于“稳定”的下一步

目前还没有直接规定稳定阈值。

下一步应该先通过固定 PWM 实验观察电机实际运行时的自然速度波动，再确定：

两次测速之间变化小于多少 RPM

才可以认为变化较小。

目前暂时考虑：

连续 3 次满足稳定条件

作为第一版候选。

Encoder 每约 0.2 秒产生一次有效测速，因此连续 3 次大约对应 0.6 秒。

但这个数值不是最终固定参数，最终应根据实际实验结果决定。
