今日主题：Controller 第一版接口设计

从已完成的 Motor 层进入 Controller 设计。

明确职责：

Motor：负责执行控制输出。

Controller：负责根据目标和当前状态决定控制输出。


初步确定 Controller 状态：

target_speed

current_speed

output


初步确定接口：

set_target_speed()

update_output()


理解 target_speed 与 output 不是同一个概念。

理解 Controller 不应直接操作 PWM，而应通过 Motor.set_speed() 输出控制量。

理解开环控制的局限：仅知道输出指令，无法知道真实速度。

理解闭环控制需要反馈，并自然引出了编码器。

初步理解： target → error → controller → output → motor → feedback

暂未决定第一版 Controller 是否加入真实反馈。


**下一步：**决定第一版 Controller 是否先做无反馈版本，以及反馈/编码器如何接入。
