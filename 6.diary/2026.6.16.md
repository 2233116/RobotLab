
今日学习内容：

1. 完成Button软件防抖逻辑理解

理解：
current_time - last_pressed_time > 50

作用不是检测乱码，

而是忽略50ms内产生的所有重复触发。

本质：
只允许一次有效按下事件通过。


2. 理解return执行机制

if 条件满足：

return True

函数立即结束。

后面的代码不会继续执行。

因此：

if:
    return True

return False

能够正确返回按键状态。


3. 理解enable状态变量

enable为布尔变量：

True
False

按下ButtonA：

enable = not enable

实现开关机效果。

即使按钮松开，

enable状态仍然保存在对象成员变量中。
