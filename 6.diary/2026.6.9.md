问题2：函数内部修改 last_time 无效

现象： 将慢闪和快闪封装成函数后，闪烁逻辑异常。

原因： 函数参数 last_time 为局部变量：

def state_2(now, last_time, led): last_time = now 

修改后不会自动更新主循环中的 last_time。

解决方法： 使用 return 返回新的 last_time：

def state_2(now, last_time, led): ... return last_time 

主循环接收返回值：

last_time = state_2(now, last_time, led) 

问题3：重复调用函数

错误写法：

state_2(...) last_time = state_2(...) 

导致函数执行两次。

认识到：

a = func() 

本身就已经执行了函数， 赋值只是顺便接收返回值。
