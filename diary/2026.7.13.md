完成了什么：

完成 Motor 类第一版整体设计与代码完善。

学习了 MicroPython 中 PWM 对象的正确创建方式，并修改了 PWMA 的初始化。

完成 forward()、backward() 调用 set_speed() 的接口设计，避免重复编写调速逻辑。

完成 set_speed() 的速度限制（0～100）和速度到 PWM 占空比（0～65535）的转换。

完善 stop()，使其调用 set_speed(0)，保证软件状态与 PWM 输出保持一致。

学习了 self 在类中调用自身属性和方法的作用，理解了为什么类内部需要使用 self.set_speed() 而不是直接调用 set_speed()。

进行了第一次完整的 Code Review，对代码结构进行了检查和优化。


遇到什么问题：

1. PWM 对象创建方式写错，把引脚号直接传给了 PWM。


2. set_speed() 中速度没有转换为 duty_u16() 需要的范围。


3. stop() 最初没有关闭 PWM 输出，导致软件状态与硬件状态不一致。


4. if...elif... 判断链中，把"是否与当前速度相同"放在了 elif 中，导致部分情况下无法正确跳过无效更新。


5. 对 self.set_speed() 与 set_speed() 的区别理解不够清晰。



怎么解决的：

学习了 PWM(Pin(...)) 的创建方式。

使用比例映射，将 speed 转换为 0～65535 的占空比。

在 stop() 中调用 set_speed(0)，统一管理速度和 PWM。

理解了"先修正数据，再统一判断是否变化，再统一更新"的设计思路。

明确 self 表示当前对象，类内部调用自己的方法必须通过 self。
